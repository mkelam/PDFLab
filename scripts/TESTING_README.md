# PDFLab Staging Test Scripts

Automated test runner scripts for executing all 52 staging-compatible tests against the PDFLab staging environment.

## 🎯 Quick Start

### Run All 52 Tests (Full Suite)
```bash
npm run test:staging:all
```

### Run Critical Tests Only (P0)
```bash
npm run test:staging:all:quick
```

### Run Tests with HTML Report
```bash
npm run test:staging:all:report
```

---

## 📋 Available Scripts

### 1. **run-staging-tests.js** (Node.js - Cross-platform)
Main test runner that executes all staging-compatible tests.

**Usage:**
```bash
# Run all tests
node scripts/run-staging-tests.js

# Quick mode (P0 critical tests only)
node scripts/run-staging-tests.js --quick

# E2E tests only
node scripts/run-staging-tests.js --e2e

# API integration tests only
node scripts/run-staging-tests.js --api

# Skip performance tests
node scripts/run-staging-tests.js --skip-performance

# Generate HTML report
node scripts/run-staging-tests.js --report

# Verbose output
node scripts/run-staging-tests.js --verbose
```

**Features:**
- ✅ Runs all 52 staging-compatible tests
- ✅ Color-coded console output
- ✅ Progress tracking with estimated times
- ✅ JSON test results (saved to `test-results/staging-test-results.json`)
- ✅ Automatic k6 detection
- ✅ Suite prioritization (P0 → P5)
- ✅ Exit codes (0 = pass, 1 = fail)

---

### 2. **run-staging-tests.ps1** (PowerShell - Windows optimized)
PowerShell version with better Windows compatibility.

**Usage:**
```powershell
# Run all tests
.\scripts\run-staging-tests.ps1

# Quick mode (P0 critical tests only)
.\scripts\run-staging-tests.ps1 -Quick

# E2E tests only
.\scripts\run-staging-tests.ps1 -E2EOnly

# API integration tests only
.\scripts\run-staging-tests.ps1 -ApiOnly

# Skip performance tests
.\scripts\run-staging-tests.ps1 -SkipPerformance

# Generate HTML report
.\scripts\run-staging-tests.ps1 -Report

# Verbose output
.\scripts\run-staging-tests.ps1 -Verbose
```

---

### 3. **cleanup-staging-test-data.ps1**
Cleans up test data created during staging test runs.

**Usage:**
```powershell
# Interactive cleanup (asks for confirmation)
.\scripts\cleanup-staging-test-data.ps1

# Force cleanup (skip confirmations)
.\scripts\cleanup-staging-test-data.ps1 -Force

# Dry run (show what would be deleted)
.\scripts\cleanup-staging-test-data.ps1 -DryRun

# Verbose output
.\scripts\cleanup-staging-test-data.ps1 -Verbose
```

**What it cleans:**
- ✅ Test user conversion jobs
- ✅ Test feedback submissions
- ✅ Test batch processing jobs
- ✅ Test beta applications
- ✅ Uploaded test files

## 🚀 CI/CD Integration

### GitHub Actions
```yaml
name: Staging Tests

on:
  push:
    branches: [staging, main]
  schedule:
    - cron: '0 2 * * *'  # Daily at 2 AM

jobs:
  staging-tests:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v3
      - uses: actions/setup-node@v3
        with:
          node-version: '20'

      - name: Install dependencies
        run: npm ci

      - name: Run staging tests
        run: npm run test:staging:all

      - name: Upload test results
        if: always()
        uses: actions/upload-artifact@v3
        with:
          name: staging-test-results
          path: |
            test-results/
            playwright-report-staging/
```

### GitLab CI
```yaml
staging-tests:
  stage: test
  script:
    - npm ci
    - npm run test:staging:all
  artifacts:
    when: always
    paths:
      - test-results/
      - playwright-report-staging/
  only:
    - staging
    - main
```

## 🐛 Troubleshooting

### Tests timing out
**Solution**: Increase timeouts in `tests/e2e/playwright.config.staging.ts`:
```javascript
timeout: 60000, // 60 seconds
navigationTimeout: 30000, // 30 seconds
```

### k6 not found
**Solution**: Install k6 or skip performance tests:
```bash
node scripts/run-staging-tests.js --skip-performance
```

### Network errors
**Solution**: Check staging server status:
```bash
curl http://141.136.44.168:3007/health
```

### Permission errors (PowerShell)
**Solution**: Run PowerShell as Administrator or set execution policy:
```powershell
Set-ExecutionPolicy -ExecutionPolicy RemoteSigned -Scope CurrentUser
```
