# PDFLab Production Deployment Checklist

**Version:** 3.0.0
**Last Updated:** 2025-11-01
**Deployment Method:** Docker Compose (Docker Hub)
**Deployment Target:** Hostinger VPS or any Docker-enabled server

---

## 🔧 Pre-Deployment Setup

### Step 1: Upload Files to VPS

- [ ] Upload deployment scripts to VPS
  ```bash
  scp -r scripts/* your-username@your-vps-ip:/opt/pdflab/
  scp docker-compose.production.yml your-username@your-vps-ip:/opt/pdflab/
  scp .env.production.example your-username@your-vps-ip:/opt/pdflab/
  ```

### Step 2: Install Docker & Docker Compose

- [ ] Install Docker
  ```bash
  curl -fsSL https://get.docker.com -o get-docker.sh
  sudo sh get-docker.sh
  sudo usermod -aG docker $USER
  ```

- [ ] Install Docker Compose
  ```bash
  sudo curl -L "https://github.com/docker/compose/releases/latest/download/docker-compose-$(uname -s)-$(uname -m)" -o /usr/local/bin/docker-compose
  sudo chmod +x /usr/local/bin/docker-compose
  ```

### Step 3: Run Environment Setup Script

- [ ] Run `setup-env.sh` to create production `.env` file
  ```bash
  cd /opt/pdflab
  sudo bash setup-env.sh
  ```

- [ ] **Provide Required Information:**
  - [ ] API URL (e.g., `https://api.pdflab.com`)
  - [ ] CloudConvert API key (from https://cloudconvert.com/dashboard)
  - [ ] PayFast Merchant ID and Key (from https://www.payfast.io/)
  - [ ] CORS origins (your frontend domain)

- [ ] **Save Generated Credentials:**
  - [ ] Database password (auto-generated)
  - [ ] Redis password (auto-generated)
  - [ ] JWT secret (auto-generated)
  - [ ] PayFast passphrase (auto-generated)

- [ ] **Delete credentials file after saving:**
  ```bash
  sudo rm /opt/pdflab/credentials.txt
  ```

### Environment Variables Checklist

**Auto-Generated by setup-env.sh:**
- [ ] `DB_PASSWORD` - Strong 32-char password
- [ ] `REDIS_PASSWORD` - Strong 32-char password
- [ ] `JWT_SECRET` - 64-char secret
- [ ] `PAYFAST_PASSPHRASE` - 24-char passphrase

**You Must Provide:**
- [ ] `API_URL` - Your production API domain
- [ ] `CLOUDCONVERT_API_KEY` - Production API key
- [ ] `PAYFAST_MERCHANT_ID` - Production merchant ID
- [ ] `PAYFAST_MERCHANT_KEY` - Production merchant key
- [ ] `CORS_ORIGIN` - Your frontend domain(s)

## 🚀 Server Setup

### ✅ Backend Deployment (Python FastAPI)

- [ ] **Server Requirements**
  - Python 3.11+
  - Poetry installed
  - Nginx or Apache for reverse proxy
  - SSL/TLS certificate (Let's Encrypt)

- [ ] **Install Dependencies**
  ```bash
  cd backend-python
  poetry install --no-dev
  ```

- [ ] **Configure Process Manager (Supervisor/systemd)**
  ```ini
  [program:pdflab-api]
  command=/path/to/poetry run uvicorn app.main:app --host 0.0.0.0 --port 3007 --workers 4
  directory=/path/to/PDFLab/backend-python
  user=www-data
  autostart=true
  autorestart=true
  redirect_stderr=true
  stdout_logfile=/var/log/pdflab/api.log
  ```

- [ ] **Nginx Reverse Proxy Configuration**
  ```nginx
  server {
      listen 443 ssl http2;
      server_name api.pdflab.pro;

      ssl_certificate /etc/letsencrypt/live/api.pdflab.pro/fullchain.pem;
      ssl_certificate_key /etc/letsencrypt/live/api.pdflab.pro/privkey.pem;

      location / {
          proxy_pass http://127.0.0.1:3007;
          proxy_set_header Host $host;
          proxy_set_header X-Real-IP $remote_addr;
          proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
          proxy_set_header X-Forwarded-Proto $scheme;
      }
  }
  ```

## 📝 Rollback Plan

If critical issues occur:

1. **Database Rollback**
   ```bash
   poetry run alembic downgrade -1  # Rollback one migration
   ```

2. **Code Rollback**
   ```bash
   git revert HEAD
   git push origin main
   ```

3. **Service Restart**
   ```bash
   sudo systemctl restart pdflab-api
   sudo systemctl restart pdflab-celery
   ```
