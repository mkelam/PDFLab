## SECTION 5: ON-PAGE SEO CHECKLIST

### **Technical SEO Requirements**

**Page Speed:**
- ✅ Target: <2 seconds load time
- ✅ Optimize images (WebP format, lazy loading)
- ✅ Minify CSS/JS
- ✅ Use CDN for static assets
- ✅ Enable GZIP compression

**Mobile Optimization:**
- ✅ Responsive design
- ✅ Touch-friendly buttons (44x44px minimum)
- ✅ No horizontal scrolling
- ✅ Font size 16px minimum

**Core Web Vitals:**
- ✅ LCP (Largest Contentful Paint): <2.5s
- ✅ FID (First Input Delay): <100ms
- ✅ CLS (Cumulative Layout Shift): <0.1

**Schema Markup:**
- ✅ Organization schema (homepage)
- ✅ Article schema (blog posts)
- ✅ HowTo schema (tutorial posts)
- ✅ FAQ schema (where applicable)
- ✅ Breadcrumb schema

---

### **Content SEO Guidelines**

**Title Tag Template:**
```
[Primary Keyword]: [Benefit/Promise] ([Year/Qualifier])

Examples:
- "PDF to PowerPoint Converter: Convert in 5 Seconds (Free Trial)"
- "How to Convert PDF to Word Without Losing Formatting (2026 Guide)"
- "Adobe Acrobat Alternative: 7 Cheaper Options That Work"
```

**Meta Description Template:**
```
[Hook/Problem] [Solution] [Benefit] [CTA]

Examples:
- "Struggling with PDF formatting? Our converter preserves 99% of layouts. Try 3 conversions free, no signup required."
- "Adobe too expensive? These 7 alternatives offer the same quality at 50-70% lower cost. Compare features & pricing."
```

**Header Structure:**
```
H1: [Primary Keyword + Benefit] (Only one per page)
H2: [Secondary Keywords, Section Headers]
H3: [Sub-sections, Supporting Points]

Example:
H1: How to Convert PDF to PowerPoint Without Losing Formatting
  H2: Why PDF to PowerPoint Conversion Loses Formatting
    H3: Common Formatting Issues
    H3: How Good Converters Preserve Layouts
  H2: Method 1: Using PDFLab (Recommended)
    H3: Step 1: Upload Your PDF
    H3: Step 2: Select PowerPoint Format
  H2: Method 2: Using Adobe Acrobat
  H2: Method 3: Using Smallpdf
```

**Content Length:**
- Product pages: 1,000-1,500 words
- How-to guides: 2,000-3,000 words
- Comparison posts: 2,500-4,000 words
- Roundup posts: 3,000-5,000 words

**Keyword Density:**
- Primary keyword: 0.5-1.5% (natural placement)
- Secondary keywords: 0.3-0.8%
- LSI keywords: Sprinkle naturally

**Internal Linking:**
- 3-5 internal links per post
- Link to product pages from guides
- Link to related guides from each other
- Use descriptive anchor text (not "click here")

**Call-to-Action Placement:**
- After intro (soft CTA: "Try free")
- Mid-content (contextual: "Convert your PDF now")
- End of post (strong CTA: "Start converting today")
- Sidebar (persistent CTA)
